# MVP-020 — امتیازدهی توزیع فرد/زوج و صبح/عصر

**وضعیت:** پیاده‌سازی‌شده  
**دامنه:** محاسبه معیار `SC_TIME_PATTERN_DIVERSITY` برای کلاس‌های انتخاب‌شده هر Requirement

## الگوی هدف

| تعداد کلاس موردنیاز | الگوی مطلوب                                                      |
| ------------------: | ---------------------------------------------------------------- |
|                   ۱ | بهترین Slot از نظر پوشش؛ بدون جریمه تنوع                         |
|                   ۲ | دو گروه متفاوت در هر دو محور روز و زمان، مانند فرد صبح و زوج عصر |
|                   ۳ | سه گروه متمایز از چهار گروه اصلی                                 |
|                   ۴ | یک کلاس در هر گروه اصلی                                          |
|          بیشتر از ۴ | استفاده از هر چهار گروه با اختلاف تعداد حداکثر یک                |

چهار گروه اصلی `ODD_MORNING`، `ODD_EVENING`، `EVEN_MORNING` و `EVEN_EVENING` هستند. گروه خنثی معتبر است اما نیاز تنوع فرد/زوج را تأمین نمی‌کند. گروه `MIXED` در شمارش تنوع مؤثر، نیم امتیاز یک گروه اصلی را دارد.

## فرمول

ابتدا امتیاز محور روز و زمان محاسبه می‌شود:

```text
axisScore = dayAxisScore × 0.60 + timeAxisScore × 0.40
normalizedScore = axisScore × groupDiversityScore × balanceScore
weightedPoints = normalizedScore × configuredWeight
```

`groupDiversityScore` مانع آن می‌شود که تکرار دو گوشه قطری برای نیاز چهارکلاسه امتیاز کامل بگیرد. `balanceScore` برای بیش از چهار کلاس، اختلاف توزیع چهار گروه اصلی را جریمه می‌کند.

امتیاز نرمال‌شده با چهار رقم و امتیاز وزنی با دو رقم اعشار گرد می‌شود. وزن پیش‌فرض ۲۵ است، اما سرویس وزن صحیح بین صفر تا صد را از تنظیمات مؤثر آموزشگاه می‌پذیرد.

## هشدارها

- `MISSING_SCHEDULED_CLASSES`: تعداد کلاس انتخاب‌شده از نیاز کمتر است؛
- `NEUTRAL_TIME_GROUP_USED`: حداقل یک کلاس در گروه خنثی قرار دارد؛
- `TIME_PATTERN_NOT_DIVERSE`: الگوی مطلوب کامل نشده است؛
- `TIME_GROUP_IMBALANCED`: توزیع بیش از چهار کلاس متوازن نیست.

## خروجی

خروجی شامل تعداد هر هشت گروه، تعداد گروه‌های اصلی متمایز، امتیاز دو محور، امتیاز تنوع گروه، امتیاز تعادل، Criterion استاندارد و هشدارهای ساخت‌یافته است. قرارداد Zod تطابق تعداد انتخاب‌شده با group count و تعداد موردنیاز را کنترل می‌کند.

این مرحله فقط یک مجموعه کلاس انتخاب‌شده را امتیازدهی می‌کند و هنوز عملیات انتخاب نهایی، ذخیره Proposal یا ساخت Class انجام نمی‌دهد.

## معیار پذیرش

- [x] نیاز یک‌کلاسه بابت نبود تنوع جریمه نمی‌شود.
- [x] دو کلاس قطری امتیاز کامل می‌گیرند.
- [x] برای سه و چهار کلاس، تعداد گروه‌های متمایز کنترل می‌شود.
- [x] بیش از چهار کلاس براساس تعادل چهار گروه اصلی ارزیابی می‌شود.
- [x] نسبت ۶۰٪ محور روز و ۴۰٪ محور زمان اعمال می‌شود.
- [x] گروه‌های خنثی و ترکیبی رفتار صریح دارند.
- [x] وزن قابل تنظیم آموزشگاه در weighted points اعمال می‌شود.
- [x] هشدارها و breakdown قابل توضیح هستند.
