# MVP-016 — پیش‌بررسی اجرای زمان‌بندی

**وضعیت:** پیاده‌سازی‌شده  
**دامنه:** تشخیص داده‌های مسدودکننده و هشدارها پیش از ورود به موتور تولید کاندید

## هدف

Preflight از شروع اجرای بی‌نتیجه جلوگیری می‌کند و نتیجه را به‌صورت ساخت‌یافته روی `SchedulingRun.preflightReport` ذخیره می‌کند. گزارش شامل نسخه قرارداد، زمان بررسی، وضعیت عبور، شمارنده‌ها و Issueهای دارای `code`، `severity`، `scope`، `entityId` و `context` است.

## قواعد مسدودکننده

برای هر Course موجود در Requirementهای اجرا:

- نبود استاد فعال با نقش `TEACHER` و Qualification معتبر، خطای `COURSE_WITHOUT_QUALIFIED_TEACHER` ایجاد می‌کند؛
- وجود استاد واجد شرایط بدون هیچ Availability ثبت‌شده، خطای `COURSE_WITHOUT_AVAILABLE_TEACHER` ایجاد می‌کند.

وجود هر Issue با شدت `BLOCKING` باعث می‌شود Run با وضعیت `PREFLIGHT_FAILED`، کد `PREFLIGHT_BLOCKED` و زمان پایان ذخیره شود. در این حالت هیچ `SchedulingPlan` یا `Class` ساخته نمی‌شود.

## هشدارهای غیرمسدودکننده

- نبود اتاق فعال با ظرفیت کافی برای یک Requirement حضوری با `NO_CLASSROOM_WITH_REQUIRED_CAPACITY` گزارش می‌شود. موتور می‌تواند آن Requirement را بعداً حل‌نشده ثبت کند.
- ناقص بودن اطلاعات زمانی بخشی از زبان‌آموزان با `INCOMPLETE_STUDENT_SCHEDULE_DATA` گزارش می‌شود و مانع اجرا نیست.
- نبود زبان‌آموز واجد شرایط با `NO_ELIGIBLE_STUDENTS` و شدت `INFO` ثبت می‌شود؛ معیار پوشش برای این حالت بعداً `NOT_APPLICABLE` خواهد بود.
- تعداد استادان فعال بدون هیچ Qualification با `TEACHERS_WITHOUT_COURSE_QUALIFICATION` و شدت `INFO` گزارش می‌شود.

## رفتار اجرای موفق

اگر Issue مسدودکننده وجود نداشته باشد، Run با وضعیت `QUEUED` و Plan پیش‌نویس ساخته می‌شود. هشدارهای Preflight در گزارش باقی می‌مانند تا موتور و رابط بررسی بتوانند آن‌ها را نمایش دهند.

## معیار پذیرش

- [x] گزارش Preflight دارای قرارداد Zod مشترک است.
- [x] Course بدون استاد واجد شرایط یا استاد دارای Availability، اجرا را مسدود می‌کند.
- [x] کمبود ظرفیت اتاق و داده ناقص زبان‌آموز به‌عنوان هشدار غیرمسدودکننده ثبت می‌شود.
- [x] شمارنده‌های گزارش و مقدار `passed` با Issueها سازگار اعتبارسنجی می‌شوند.
- [x] Run شکست‌خورده برای ممیزی ذخیره می‌شود و Plan یا Class نمی‌سازد.
- [x] اجرای موفق همراه گزارش Preflight وارد صف می‌شود.
