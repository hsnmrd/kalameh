# MVP-033 — زیرساخت رابط کاربری زمان‌بندی

**وضعیت:** پیاده‌سازی‌شده  
**دامنه:** نقطه ورود UI برای چرخه زمان‌بندی خودکار

## مسیر و دسترسی

صفحه جدید در مسیر زیر در دسترس است:

```text
/{locale}/scheduling
```

این صفحه زیر `AdminBaseLayout` قرار دارد، به ماژول `CLASSES_COURSES` وابسته است و مجوز `VIEW_CLASSES` را کنترل می‌کند. لینک «زمان‌بندی هوشمند» نیز به ناوبری دسکتاپ و منوی responsive اضافه شده است.

## قرارداد UI

- محتوای فارسی و انگلیسی در namespace مستقل `scheduling` نگهداری می‌شود؛
- layout صفحه همیشه پیام‌های `common` و `scheduling` را با هم بارگذاری می‌کند؛
- مسیر چهاربخشی آماده‌سازی، تولید، بازبینی و انتشار برای سوپروایزر نمایش داده می‌شود؛
- لینک‌های عملی برای بررسی ترم‌ها، استادان و فراگیران در حالت شروع وجود دارند؛
- صفحه در موبایل و دسکتاپ از همان معماری responsive پنل مدیریت استفاده می‌کند.

## لایه API فرانت‌اند

`schedulingResource` همه endpointهای فعلی زمان‌بندی را با micro-rq تعریف می‌کند:

- تولید Run؛
- polling وضعیت Run؛
- دریافت جزئیات Plan؛
- انتخاب و اعتبارسنجی Plan؛
- انتشار Plan؛
- ویرایش و قفل Proposal.

این resourceها در مراحل بعد مستقیماً از طریق `.toQuery()` و `.toMutation()` به TanStack Query داده می‌شوند.

## مرز این تسک

فرم تولید برنامه، نمایش progress اجرای الگوریتم، مقایسه Planها و review/publish تعاملی عمداً در MVP-033 پیاده‌سازی نشده‌اند و در تسک‌های بعد روی این زیرساخت اضافه می‌شوند.
